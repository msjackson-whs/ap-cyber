Glossary

What each command means, in plain English.

hostname
The switch's name.
username … secret …
Creates an admin account stored on this switch, with its password.
interface FastEthernet0/3
The settings below it are for port 3. Ports go up to 0/6. GigabitEthernet0/1 is a faster port.
description
A note describing what is plugged into the port.
switchport mode access
The port connects to a single device, like a computer.
switchport port-security
Turns port security on for this port.
… maximum 2
At most 2 MAC addresses may use this port.
… violation shutdown
If the rules are broken, shut the port down.
… mac-address sticky
Lock in the first MAC address(es) the port sees.
… mac-address 0050.56a1.2b3c
Only allow this specific MAC address.
shutdown / no shutdown
Turn the port off / turn the port on.
line vty 0 4
The settings below it are for remote admin logins.
login local
Check admin logins against accounts stored on this switch.
transport input ssh
Allow remote admin logins only through SSH.
